GHTrend · GitHub 星速榜 —— 第一次使用请看这里
================================================

这是一个本地小工具：每天告诉你 GitHub 上哪些项目 star 涨得最快，
并用大白话解释每个项目到底是干什么的。

不用安装、不用注册、不上传任何数据。


────────────────────────────────────────
第一步：确认这台电脑有 Python
────────────────────────────────────────

双击「打开界面.bat」。

  · 如果几秒后弹出一个窗口 → 跳过，直接看第二步
  · 如果提示 Python was not found → 需要先装 Python：
      1. 打开 https://www.python.org/downloads/
      2. 下载安装，安装界面务必勾选
           [x] Add python.exe to PATH
      3. 装完重新双击「打开界面.bat」

（Python 是免费的，只是一个运行环境，装完就不用管了。）


────────────────────────────────────────
第二步：抓一次数据
────────────────────────────────────────

窗口打开后会提示「今天还没有数据」。
点右上角绿色的「抓取最新数据」，等大约 1 分钟。

抓取过程中顶部会有一条进度条，显示真实的抓取进度。


────────────────────────────────────────
第三步：怎么看
────────────────────────────────────────

每一行长这样：

  1   像请了个随叫随到的私人助理，把电脑里散落的文件自动归位
      astral-sh/uv  ·  Rust  ·  [AI 人话]              48,000★
                                         在 GitHub 查看 →

  · 开头的粗体句子 = 这个项目能帮你干什么（点它可以展开详细说明）
  · 下面小字 = 项目名、语言
  · 右边数字 = 24 小时涨了多少 star、总共多少 star
  · 右下角「在 GitHub 查看」= 打开项目主页


────────────────────────────────────────
关于「新星榜」和「日增榜」
────────────────────────────────────────

第一次打开显示的是「新星榜」——按项目年龄算增长速度。
这是因为日增 = 今天减昨天，本地只有一天的数据算不出来。

第二天再打开，就会自动变成真正的「日增榜」。


────────────────────────────────────────
可选：让标题更聪明
────────────────────────────────────────

默认标题是「一个用 Rust 写的图像工具」这类按关键词生成的，
能看懂方向，但说不出“能干什么”。

想要「像请了个随叫随到的私人助理…」这种人话，需要配一个大模型（LLM）：

  双击「启动.bat」→ 选 8 → 按提示粘贴密钥

也可以用命令行： python ghtrend.py setup

不配也完全能用，只是标题朴素一些。


────────────────────────────────────────
常见问题
────────────────────────────────────────

问：抓取失败 / 一直转圈？
答：多半是网络连不上 GitHub。打开「启动.bat」选 7，会告诉你哪条线路能通。
    程序默认会自动换镜像，通常不用管。

问：窗口点了没反应？
答：看 logs\server.log，里面记录了启动过程和报错。

问：数据存在哪？会上传吗？
答：全部存在本机这个文件夹的 data\ 目录里，什么都不会上传。

问：想每天自动跑？
答：用 run_daily.bat 配合 Windows「任务计划程序」，详见 README.md。


更多说明见 README.md（技术细节、配置项、接口文档都在里面）。
